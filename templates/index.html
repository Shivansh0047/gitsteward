Your code evolves.
Your documentation should too.

GitSteward is a GitHub App that detects potentially outdated README sections after code changes and proposes documentation updates through reviewable pull requests — keeping developers in control of every change.

Why GitSteward?

Documentation maintenance, automated.

Reduce the gap between implementation and documentation without giving an AI agent unchecked control over your repo.

⌕

Context-Aware Detection

Uses code diffs, semantic retrieval and an LLM to identify README sections that may no longer reflect the implementation.

✦

AI-Powered Rewriting

Generates proposed section updates using the relevant code changes and existing documentation as context.

⑂

Human-in-the-Loop

Publishes suggestions on a dedicated documentation branch and opens a pull request for human review. GitSteward does not merge its own proposals.

The workflow

From code push to reviewed PR

An event-driven pipeline that connects GitHub, retrieval-augmented analysis and controlled documentation updates.

1

Push

A commit lands on the main branch.

2

Analyze

GitSteward examines the changed code.

3

Detect

4

Propose

5

A pull request awaits a human decision.

Getting started

How to use GitSteward

GitSteward is an event-driven GitHub App, not a public chatbot. Its analysis begins when a configured repository receives a qualifying push.

1

Request repository access

Contact the repository owner to request access to the GitSteward GitHub App and confirm whether your repository can be configured for testing.

2

Install and authorize the GitHub App

The repository owner must ensure the app is installed on the repository with the required permissions and webhook events.

3

Push a code change to main

After setup, push a commit to the main branch. GitSteward analyzes the changed files and retrieves relevant README context.

4

Review the generated pull request

If potentially stale documentation is detected, inspect the proposed changes in the GitHub pull request and decide whether to accept them.

🔐 Access & credentials

GitSteward requires server-side configuration, including GitHub App credentials and AI provider API keys. These are not publicly exposed. For authorized testing, app access, or setup assistance, please contact the repository owner through the owner's GitHub profile . Never share personal passwords, API keys, or private credentials in a public issue.
